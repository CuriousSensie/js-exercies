# Tintash

## Contents

The `js-ex` repository contains solutions to a small set of JavaScript practice problems.

- `js-ex/problem1_functions.js` - function basics
- `js-ex/problem2_arrays.js` - array prototype work and URL population
- `js-ex/problem3_closures.js` - closure-based chaining
- `js-ex/problem4_memoization.js` - simple request memoization
- `js-ex/problem5_async.js` - callbacks, promises, and async/await
- `js-ex/problem6_observables.js` - observer pattern and streaming updates

## Notes

The examples are written as standalone exercises and can be run individually with Node.js.

```console
node js-ex/problem1_function.js
```
